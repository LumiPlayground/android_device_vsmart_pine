# Device configurations for Vsmart Joy 2+ (pine)

The Vsmart Joy 2+ (codenamed "pine") is a mid-range smartphone from Vsmart.

## Device specifications
| Basic                   | Spec sheet                                                                    |
| -----------------------:|:----------------------------------------------------------------------------- |
| CPU                     | Octa-core (8x1.8 GHz ARM Cortex-A53)                                          |
| Chipset                 | Qualcomm SDM450 Snapdragon 450 (14 nm)                                        |
| GPU                     | Adreno 506                                                                    |
| Memory                  | 2/3 GB RAM                                                                    |
| Shipped Android Version | Android 9 (Pie), upgradeable to Android 10 (Q)                                |
| Storage                 | 32 GB eMMC 5.1                                                                |
| Battery                 | Non-removable Li-Ion 5000 mAh battery                                         |
| Display                 | 720 x 1520 pixels, 19:9 ratio (~271 ppi density)                              |
| Camera (Back)           | 13 MP, f/2.0 (wide), 5 MP, f/2.4 (Macro)                                      |
| Camera (Front)          | 8 MP, f/2.2                                                                   |
